# المؤرخ — منصة مستر شريف

موقع كامل في ملف واحد (`index.html`): أدمن ومدرس وطالب، حضور بكود، انضباط، واجبات، درجات، فيديوهات، إعلانات، جدول.

## التشغيل
- محليًا: دبل كليك على `index.html`.
- على الإنترنت: GitHub → Settings → Pages → Branch: main → Folder: / (root) → Save.

## أول مرة
الموقع بيطلب منك تختار كلمة مرور للأدمن (`sherif` و `ahmed`). مفيش أي باسورد جاهز في الكود.

## تنبيه مهم
البيانات بتتخزن في متصفح كل جهاز (localStorage) ومش بتتشارك بين الأجهزة. استخدم "نسخة احتياطية" من القائمة بانتظام.
